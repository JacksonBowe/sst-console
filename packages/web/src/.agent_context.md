# Web App Source Map

- `boot/` initializes Vue Query, API client/session refresh, then auth route protection.
- `components/App/Detail/Stage/` contains stage overview, Updates history, resource explorer, and Function page; `components/LocalWorkspace/` contains live local-invocation UI. Other `components/` domains cover app/account/auth/console and reusable `ui/` primitives.
- `components/ui/` contains local reusable Quasar UI primitives: auth, inputs, tables, dialogs, drawers, dashboards, previews, tabs, identifiers, and form/theme helpers.
- `pages/MonitoringPage.vue` owns Monitoring route layout and tab state; `components/Monitoring/` holds tab content and tab-specific header actions, with issue UI in `components/Monitoring/Issues/`.
- `pages/Stage/` contains stage Overview and Functions pages; `pages/LocalWorkspacePage.vue` renders standalone or contextual local SST dev activity.
- `pages/AuthPage.vue` binds Console auth mutations to `components/ui/Auth/CognitoAuth.vue` with public sign-up disabled.
- `pages/UsersPage.vue` lists and filters Console users; `components/Users/` contains user actions and `composables/users.ts` owns user queries and mutations.
- `composables/auth.ts` wraps SDK auth methods in TanStack Vue Query mutations.
- `composables/useAutoFetchAllPages.ts` automatically loads remaining infinite-query pages when a view needs the complete dataset.
- `layouts/AuthLayout.vue` centers public auth routes; `layouts/ConsoleLayout.vue` contains protected console routes.
- `components/Console/ConsoleSettingsDialog.vue` groups local appearance preferences in the sidebar Settings dialog.
- `stores/auth.ts` persists Cognito sessions with Quasar `LocalStorage`; `stores/local-session.ts` owns permission-gated Console-wide local SST CLI WebSocket state; `stores/ui-settings.ts` persists appearance preferences together.
- `composables/theme.ts` applies stored light/dark/system preferences and theme CSS variables.
- `util/redact.ts` partially masks standard API, authentication, and AWS credential values and fully masks client IP fields; `util/json.ts` parses JSON request and response bodies for safe display and copying.
- `composables/apps/` owns stage resource category/filter helpers; `composables/local/` matches sessions to stages, classifies local invocation outcomes, and defines local-session types.
- `composables/state-history.ts` owns stage history queries, discovery, and processing mutations.
- `router/routes.ts` defines protected console routes, including dedicated stage Functions, and guest-only `/login` routes.
