# Web App Source Map

- `boot/` initializes Vue Query, API client/session refresh, then auth route protection.
- `components/ui/` contains local reusable Quasar UI primitives: auth, inputs, tables, dialogs, drawers, dashboards, previews, tabs, and form/theme helpers.
- `pages/AuthPage.vue` binds Console auth mutations to `components/ui/Auth/CognitoAuth.vue` with public sign-up disabled.
- `composables/auth.ts` wraps SDK auth methods in TanStack Vue Query mutations.
- `layouts/AuthLayout.vue` centers public auth routes; `layouts/MainLayout.vue` contains protected app routes.
- `stores/auth.ts` persists Cognito sessions with Quasar `LocalStorage`.
- `router/routes.ts` defines protected app and guest-only `/login` routes.
