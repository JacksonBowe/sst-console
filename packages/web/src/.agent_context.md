# Web App Source Map

- `boot/` initializes Vue Query, API client/session refresh, then auth route protection.
- `components/App/Detail/Stage/` contains stage overview, resource explorer, and Function page; `components/LocalWorkspace/` contains live local-invocation UI. Other `components/` domains cover app/account/auth/console and reusable `ui/` primitives.
- `components/ui/` contains local reusable Quasar UI primitives: auth, inputs, tables, dialogs, drawers, dashboards, previews, tabs, identifiers, and form/theme helpers.
- `pages/Stage/` contains stage Overview and Functions pages; `pages/LocalWorkspacePage.vue` renders standalone or contextual local SST dev activity.
- `pages/AuthPage.vue` binds Console auth mutations to `components/ui/Auth/CognitoAuth.vue` with public sign-up disabled.
- `composables/auth.ts` wraps SDK auth methods in TanStack Vue Query mutations.
- `layouts/AuthLayout.vue` centers public auth routes; `layouts/ConsoleLayout.vue` contains protected console routes.
- `stores/auth.ts` persists Cognito sessions with Quasar `LocalStorage`; `stores/local-session.ts` owns permission-gated Console-wide local SST CLI WebSocket state.
- `composables/theme.ts` persists validated light/dark preferences and applies theme CSS variables.
- `util/redact.ts` masks standard API, authentication, and AWS credential values; `util/json.ts` parses JSON request and response bodies for safe display and copying.
- `composables/apps/` owns stage resource category/filter helpers; `composables/local/` matches sessions to stages, classifies local invocation outcomes, and defines local-session types.
- `router/routes.ts` defines protected console routes, including dedicated stage Functions, and guest-only `/login` routes.
