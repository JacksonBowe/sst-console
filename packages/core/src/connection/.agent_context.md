# Connection domain

- `connection.ts`: durable Connection registry service and read/write operations.
- `connection.dynamo.ts`: ElectroDB entity for `ConsoleConnections`.
- `policy.ts`: sync-policy schema, validation, defaults, and stage-selector matching.
- `recovery.ts`: backs up Account records and restores them from durable Connections.
- `index.ts`: public Connection API and Policy namespace.
