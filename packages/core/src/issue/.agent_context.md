# Issue domain

- `issue.ts`: durable Issue contract, lifecycle changes, filtering, purge.
- `issue.dynamo.ts`: Issue, log subscription, and regional subscriber entities.
- `processor.ts` + `parser.ts`: ingress normalization, fingerprinting, occurrence persistence.
- `monitoring.ts`: Stage monitoring configuration and CloudWatch subscription reconciliation.
- `issue.subscription.ts`: persisted Console-owned CloudWatch filter records.
- Tests: `packages/core/tests/issue/`.
