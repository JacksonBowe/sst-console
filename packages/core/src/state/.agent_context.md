# State domain

- `discovery.ts`: discovers SST State objects and reconciles Stage inventory.
- `sync.ts`: fetches State projections, syncs current State, and reconciles State deletion events.
- `cleanup.ts`: schedules stale Stage projection removal.
- `inspect.ts`: reads a redacted diagnostic inventory from SST State.
- `state.ts`, `update.ts`, `state.dynamo.ts`: current State references, Update ingestion and metadata, and persistence models.
- `sst.ts`, `keys.ts`, `schema.ts`, `events.ts`, `errors.ts`: SST artifact fetching and parsing, identity helpers, contracts, and domain errors.
