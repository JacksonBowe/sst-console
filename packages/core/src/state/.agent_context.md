# State domain

- `discovery.ts`: discovers SST State objects and reconciles Stage inventory.
- `sync.ts`: syncs current State, receives Updates, and reconciles State deletion events.
- `projection.ts`: State artifact loading and removal scheduling.
- `inspect.ts`: reads a redacted diagnostic inventory from SST State.
- `state.ts`, `state.update.ts`, `state.dynamo.ts`: artifact references, queryable metadata, and discovery persistence.
- `sst.ts`, `update.ts`, `events.ts`, `errors.ts`: SST artifact parsing, event contracts, and domain errors.
