# State domain

- `discovery.ts`: discovers SST State objects and reconciles Stage inventory.
- `sync.ts`: syncs current State, receives Updates, and reconciles State deletion events.
- `projection.ts`, `ownership.ts`: projection writes, account and Stage cleanup, and ownership conflicts.
- `inspect.ts`: reads a redacted diagnostic inventory from SST State.
- `state.ts`, `state.update.ts`, `state.dynamo.ts`: current State and Update contracts and persistence.
- `sst.ts`, `events.ts`, `errors.ts`: SST bootstrap lookup and parsing, event contracts, and domain errors.
