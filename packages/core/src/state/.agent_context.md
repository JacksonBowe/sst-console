# State domain

- `discovery.ts`: discovers SST State objects, reconciles Stage inventory, and discovers historical artifact locators.
- `sync.ts`: fetches State projections, syncs current State, and reconciles State deletion events.
- `cleanup.ts`: schedules stale Stage projection removal.
- `inspect.ts`: reads a redacted diagnostic inventory from SST State.
- `state.ts`, `update.ts`, `state.dynamo.ts`: current State references, historical processing, Update ingestion and metadata, and persistence models.
- `snapshot.ts`, `event-log.ts`: Snapshot and Event Log locators and ingestion; snapshots reconcile resource events and counts.
- `resource-event.ts`: safe Resource event persistence, source merging, reads, and cleanup.
- `sst.ts`, `keys.ts`, `schema.ts`, `events.ts`, `errors.ts`: SST artifact fetching, provider-neutral safe resource projection and hierarchy, identity helpers, contracts, and domain errors.
