# Account domain

- `account.ts`: Account CRUD and listing; sole owner of Account persistence operations.
- `connector.ts`: verified account connection, assumed-role verification, and remote-access disconnect handling.
- `registration.ts`: connector callbacks, registration events, and disconnect cleanup orchestration.
- `forwarding.ts`: enables S3 notifications and reconciles the workload EventBridge rule and target.
- `sync.ts`: account-wide State sync orchestration.
- `projection.ts`: coordinates App projection and State artifact cleanup on disconnect.
- `management.ts`: sync-policy management views and apply operation.
- `schema.ts`, `errors.ts`: shared Account contracts and remote-access error classification.
- State discovery and artifact cleanup live in `../state/`; App projection operations live in `../app/`.
