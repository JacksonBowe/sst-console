# Account domain

- `account.ts`: Account CRUD and listing; sole owner of Account persistence operations.
- `connector.ts`: verified account connection, assumed-role verification, remote-access disconnect handling, and connector callbacks.
- `forwarding.ts`: enables S3 notifications and reconciles the workload EventBridge rule and target.
- `sync.ts`: account-wide State sync orchestration.
- `management.ts`: sync-policy management views and apply operation.
- `schema.ts`, `errors.ts`: shared Account contracts and remote-access error classification.
- State discovery, projection, and cleanup live in `../state/`.
